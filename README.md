# Amazon Clone 🛒

A responsive Amazon e-commerce website clone built using **HTML, CSS, and JavaScript**. This project recreates the core shopping experience of Amazon, including product browsing, cart management, checkout, order history, and order tracking.

## 🌐 Live Website

**[View the Amazon Clone Live](https://dexter-1280.github.io/Amazon-clone/)**

## 🚀 Features

- 🛍️ Product listing and browsing
- 🔎 Search bar interface
- ⭐ Product ratings and review counts
- 🛒 Add products to cart
- 🔢 Select product quantity
- 💰 Dynamic cart quantity and pricing
- 📦 Checkout page
- 🧾 Order summary
- 📋 Order history
- 🚚 Order tracking page
- 📱 Responsive design
- 💾 Product and cart data management
- 🎨 Amazon-inspired UI

## 🛒 Main Pages

### Home / Products

The main shopping page displays products with their images, names, prices, ratings, and quantity selectors. Users can add products directly to their cart.

### Checkout

The checkout page displays selected products, quantities, shipping costs, tax calculations, and the final order total.

### Orders

Users can view previously placed orders and their order information.

### Tracking

The tracking page provides an interface for viewing the delivery status of an order.

## ⚙️ How It Works

The application uses JavaScript modules to separate different parts of the application.

Product information is loaded from the project's product data, while cart functionality handles adding products, updating quantities, and calculating the total number of items in the cart.

The main product page dynamically generates product cards using JavaScript and updates the cart indicator whenever a product is added.
